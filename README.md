# Friendsgiving Pickleball Cup

Live brackets and standings for the Friendsgiving 2026 pickleball tournament.

- `index.html`: start page for picking which lineup you're using.
- `with-john/`: Option 1, 8 teams, no byes.
- `without-john/`: Option 2, 7 teams with Julie as the sub.
- `Pickleball-Option1-With-John.pdf` and `Pickleball-Option2-Without-John.pdf`: printable paper backups.

Enter scores and the standings and playoff seeds update automatically. Scores are saved in the browser of the device where they're entered, so keep score on one device.

## Deploy on Vercel

Import this repository at vercel.com/new. Leave the framework preset on "Other" with no build command; Vercel serves the files as-is.
