# Friendsgiving Pickleball Cup

Live bracket and standings for the Friendsgiving 2026 pickleball tournament: 7 teams, 4 courts, 3 rounds plus a Final and 3rd-place game.

- `index.html` is the whole site: enter scores, and the standings and playoff seeds update automatically.
- `Friendsgiving-Pickleball-Bracket.pdf` is a printable paper backup.

Scores are saved in the browser of the device where they're entered, so keep score on one device.

## Deploy on Vercel

Import this repository at vercel.com/new. Leave the framework preset on "Other" with no build command; Vercel serves `index.html` as-is.
